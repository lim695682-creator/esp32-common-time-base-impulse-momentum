# ESP32 Impulse–Momentum Lab

An ESP32-based apparatus for studying impulse and momentum during cart collisions. This repository accompanies “An ESP32-Based Apparatus with a Common Time Base for Impulse–Momentum Measurement.”

## Supplementary materials

- [S1 — Reproduction guide](supplementary_material/S1_reproduction_guide/README.md): hardware, firmware, calibration, acquisition, and analysis steps.
- [S2 — Data and provenance](supplementary_material/S2_data_and_provenance/README.md): 57 supplied trial CSV exports grouped by collision head, plus a SHA-256 manifest.
- [S3 — Figures and videos](supplementary_material/S3_figures_and_videos/README.md): apparatus photographs, diagrams, result figures, and demonstration video.

The paper cites S1 for the repeatable procedure, S2 for source data and provenance, and S3 for visual documentation. Derived results should be traceable to S2 using the method in S1.

## Existing project files

The repository also contains the ESP32 firmware, browser interface, hardware notes, and documentation. Review the calibration and wiring notes for the actual build before collecting data.
