# S2. Data and provenance

This module contains the original trial-level CSV exports supplied with the manuscript project. Files are grouped by collision head: buffered foam (EPE pearl cotton), stiff head, and collapsing head. Filenames preserve the acquisition timestamps generated by the platform.

The 57 source exports are evidence of data provenance and should be treated as read-only records. The 11 valid buffered-foam trials reported in Table II and Fig. 3 are selected from this package. Cite Supplementary Material S2 whenever trial-level values, calibration quantities, or representative traces are used.

A SHA-256 manifest should accompany the final release so that the source files can be verified.
